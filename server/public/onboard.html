Participation Consent

What data is collected:

  • Eye gaze coordinates on web pages (if eye tracker connected)
  • Mouse movements and clicks
  • Scroll position and page navigation
  • Screenshots of web pages you visit during the study
  • Browser type and screen resolution

What is NOT collected:

  • Passwords or form input content
  • Other browser tabs or personal files
  • Audio, video, or screen content outside the browser tab
  • Any data outside the tracked browser session

Your rights:

  • Participation is voluntary — you can stop at any time
  • You can request deletion of your data at any time
  • You can export your own data before it is deleted
  • You may uninstall the extension at any time

Manual Install

Step-by-step instructions for developer mode

  1. Download the extension files from your researcher or the project repository
  2. Open Chrome and navigate to chrome://extensions
  3. Enable Developer mode (toggle in top-right corner)
  4. Click Load unpacked
  5. Select the extension/ folder from the downloaded files
  6. The EyeD icon will appear in your browser toolbar
  7. Pin it by clicking the puzzle-piece icon, then the pin next to EyeD

Configure the Extension
