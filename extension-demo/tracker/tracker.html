EyeD Eye Tracker

This tool uses your webcam to track eye gaze and generate attention heatmaps on web pages.

What we access:

  • Webcam video (processed locally, never uploaded)
  • Eye position data (stays in your browser)
  • Page elements you view (for analytics)

Your privacy:

  • All eye processing happens on-device
  • Data uploads only when recording is enabled and an endpoint is configured
  • You control which data channels are collected via Settings
  • You can delete all data at any time
  • A visible green indicator shows when recording is active
